# Portfolio

## Skills

Web開発をメインにしています。<br/>
働いている時間以外は個人開発に使っておりオープンソースのプロジェクトだと[Distopia](https://distopia.top)が最高傑作です。
設計段階でDDDやクリーンアーキテクチャの考えを取り入れ、CI/CDも自動化しLintやFormatも整備することで企業と同じ水準を個人で維持しています。

ライブラリ開発に関しては現在は[mankai](https://github.com/ro80t/mankai)というさくらインターネット用の非公式APIライブラリを開発しています。<br/>
過去に開発していたものだと[svelte-hono-adapter](https://github.com/ro80t/svelte-hono-adapter)というSvelteKitで出力したサーバーをHonoで使うためのアダプターも開発しています。<br/>
ライブラリ開発では有用性のほかにも純粋な面白さも重視しており[sortman](https://github.com/ro80t/sortman)というTypeScriptで10種類以上のsortを実装したライブラリも公開しています。

それ以外だと言語開発もしていますが、トランスパイラ言語なのでコンパイラやasmの最適化に関しては無知です。
